# 🚀 AC INNOVASHOPS - E-Commerce Landing Page

Landing Page oficial de **AC INNOVASHOPS**, una tienda online optimizada para ventas por WhatsApp con modalidad de **Pago Contra Entrega** en Colombia 🇨🇴.

## 🎨 Estilo y Tecnologías
- **Estilo Visual:** Acidum Dark Neon (Modo Oscuro urbano enfocado a tráfico de TikTok e Instagram).
- **Frontend:** HTML5, CSS3, JavaScript.
- **Framework:** Tailwind CSS (via CDN).
- **Lógica Comercial:** Botones directos a WhatsApp con mensajes pre-formateados para conversión directa (CRO).
